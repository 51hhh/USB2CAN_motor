# M3508 PD/PID 调参指南

> 日期: 2026-04-11  
> 适用硬件: DJI M3508 + C620 电调  
> 适用代码: `serve_windmill_manager.cpp` 中的 `computePD()`

---

## 1. 系统控制公式

### 1.1 当前 PD 公式

```cpp
// serve_windmill_manager.cpp → computePD()
const double error_deg = target_deg - feedback_angle_deg_;
const double output = kp * error_deg - kd * feedback_rpm_;
```

数学表达：

$$i = K_p \cdot (θ_{target} - θ_{feedback}) - K_d \cdot ω_{motor}$$

其中：
| 变量 | 含义 | 单位 | 备注 |
|------|------|------|------|
| $i$ | 输出电流（发给 C620） | 整数，±16384 | C620 没有前馈通道，只接受电流指令 |
| $θ_{target}$ | 目标角度 | ° (输出轴) | 例如 `home_offset_deg_ - wind_up_angle_deg_` |
| $θ_{feedback}$ | 当前角度 | ° (输出轴) | `msg->angle * motor_direction_` |
| $ω_{motor}$ | 电机轴转速 | RPM (电机轴) | `msg->rpm * motor_direction_`，**不是输出轴转速** |

### 1.2 D 项公式详解

D 项的本质是**速度阻尼**——当臂在运动时产生一个反向制动力：

$$D = -K_d \cdot ω_{motor}$$

- 当臂**正向运动**时（$ω_{motor} > 0$），D 项为负 → **制动**
- 当臂**静止**时（$ω_{motor} = 0$），D 项为 0 → **不起作用**
- 当臂**反向运动**时（$ω_{motor} < 0$），D 项为正 → 也是**制动**（阻止反向）

这就是为什么 D 叫做"微分阻尼"——它只在有速度时起作用，像一个粘性阻力。

## 2. 减速比隐式放大——D 项的核心陷阱

### 2.1 M3508 减速比

M3508 减速比 **19.2:1**，即：

$$ω_{motor} = 19.2 \times ω_{output}$$

C620 返回的 `rpm` 字段是**电机轴转速**（典型值 ~500-3000 RPM），而 `angle` 字段是**输出轴角度**。

### 2.2 单位不匹配的后果

P 项用**输出轴度数**（°），D 项用**电机轴 RPM**，两者数值级别差距巨大：

| 项 | 计算 | 典型数值级别 |
|----|------|-------------|
| P 项 | `kp × error_deg` | kp=100, error=20° → **2000** |
| D 项 | `kd × rpm_motor` | kd=3, rpm=500 → **1500** |

如果将 D 项折算到等效输出轴阻尼：

$$K_{d,effective} = K_d \times 19.2$$

即 **代码中 kd=3 等效于输出轴阻尼 kd_output=57.6**。

### 2.3 kd=10 时发生了什么

$$K_{d,effective} = 10 \times 19.2 = 192$$

考虑运动过程中 RPM 仅为 300（输出轴约 15.6 RPM）：

$$D = 10 \times 300 = 3000$$

而 P 项（假设 kp=100, error=15°）：

$$P = 100 \times 15 = 1500$$

**D 项(3000) > P 项(1500)** → 净输出为负 → 臂被推向反方向！

这就是 **kd=10 时臂不自主转动**的根因：D 项过大，在运动过程中产生的"刹车力"超过了"推力"，导致系统进入振荡循环——前进时被 D 刹死反弹，反弹时又被 D 推回——表现为抖动或自转。

## 3. Kp 和 Kd 的调参法则

### 3.1 各参数作用

| 参数 | 物理含义 | 调大效果 | 调小效果 |
|------|----------|----------|----------|
| **Kp** | 弹簧刚度 | 响应快、稳态误差小、振荡风险↑ | 稳态误差大、响应慢 |
| **Kd** | 粘性阻尼 | 减振平滑、限制速度、抑制超调 | 超调大、到位震荡 |

### 3.2 黄金比例（M3508 经验值）

由于 `feedback_rpm_` 是电机轴 RPM（×19.2 放大），kd 必须远小于 kp：

$$K_d \approx \frac{K_p}{25 \sim 40}$$

| Kp | Kd 推荐范围 | 说明 |
|----|-------------|------|
| 80 | 2~3 | 之前的稳定参数 |
| 100 | 2.5~4 | 当前参数（kd=3 合理） |
| 200 | 5~8 | 高刚性 |
| 400 | 10~16 | 极高刚性，需前馈配合 |

### 3.3 调参步骤

1. **先调 Kp（Kd=0）**：从小到大，找到让臂能跟随目标但不振荡的值
2. **再加 Kd**：从 Kp/40 开始，逐步增加，观察超调是否减小
3. **观察稳态**：如果到位后静止有偏差 → 纯 PD 固有问题，需要前馈补偿

## 4. 稳态误差——纯 PD 的根本局限

### 4.1 稳态误差公式

臂到达平衡点时 RPM=0，D 项消失，只剩 P 项对抗重力负载：

$$K_p \times e_{ss} = τ_{load}$$

$$e_{ss} = \frac{τ_{load}}{K_p}$$

其中 $τ_{load}$ 是重力/摩擦等恒定负载对应的电流值。

| Kp | 假设 Load=2000 | 稳态误差 |
|----|----------------|----------|
| 80 | 2000/80 | **25°** |
| 100 | 2000/100 | **20°** |
| 200 | 2000/200 | **10°** |
| 400 | 2000/400 | **5°** |

**结论：纯 P 控制无法消除恒定负载下的稳态误差，除非 Kp → ∞。**

### 4.2 三种解法对比

| 方案 | 公式 | 优点 | 缺点 |
|------|------|------|------|
| A: 暴力加 Kp | `kp=400, kd=10` | 简单 | 极易振荡 |
| B: 加 I 积分 | `+ ki × ∫error·dt` | 理论零误差 | 积分饱和、超调、复杂 |
| **C: 重力前馈** | **`+ gravity_ff`** | **最干净、无振荡风险** | **需要实测确定值** |

---

## 5. 方案 C 详解：重力前馈补偿

### 5.1 原理

C620 虽然没有独立的前馈通道，但发给 C620 的电流指令就是总力矩。在软件层面，我们直接在 PD 输出上加一个固定偏移：

$$i = \underbrace{K_p \cdot e_θ - K_d \cdot ω_{motor}}_{PD 输出} + \underbrace{i_{gravity}}_{重力前馈}$$

$i_{gravity}$ 抵消恒定负载后，PD 只需处理动态偏差：

$$K_p \times e_{ss} = τ_{load} - i_{gravity} \approx 0$$

### 5.2 代码实现（伪代码）

```cpp
// handleWindUp()
const int16_t pd_output = computePD(target_deg, wind_up_kp_, wind_up_kd_, wind_up_max_current_);
sendCurrent(pd_output + gravity_ff_current_);  // gravity_ff_current_ 从 YAML 读取
```

### 5.3 如何确定 gravity_ff 的值

实测法：
1. 设 kp=0, kd=0
2. 手动发一个固定电流值（从 500 开始递增）
3. 观察：能刚好托住臂不下落 → 那就是 gravity_ff 的值
4. 一般范围：**1500 ~ 3000**（取决于臂的重量和角度）

注意：如果臂在不同角度重力矩不同，可用 $i_{gravity} = A \cdot \cos(θ)$ 做角度自适应，但对 WIND_UP 场景（固定目标角），常数值即可。

## 6. 关于"臂不自主转动"的完整解释

用户现象：**kp=100, kd=10 时，臂会不受控地自己转动/振荡**

根因分析链：

```
kd=10, motor RPM 达到 300
→ D 项 = 10 × 300 = 3000
→ P 项（error=15°）= 100 × 15 = 1500
→ D > P → 净输出反向
→ 臂被推回 → RPM 变负
→ D 项翻转 → 又推回去
→ 持续振荡 = "不自主转动"
```

等效分析：kd=10 在电机轴 RPM 上，等效于输出轴阻尼 kd_output=192，而 kp 只有 100。**阻尼系数（折算后）是弹簧系数的近 2 倍**，系统成为过阻尼-振荡交替的不稳定状态。

**解决方法**：保持 kd ≤ kp/25，即 kp=100 时 kd ≤ 4。
